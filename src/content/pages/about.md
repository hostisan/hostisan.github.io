Hostisan is a server control panel. It handles the software stack that makes web hosting work: web servers, databases, email, DNS, and security.

**Why we built it:**

Most control panels are either expensive, outdated, or both. We wanted something that looks modern, runs fast, and costs nothing.

**What it does:**

- Manage websites with Nginx and Apache
- Run MySQL, MariaDB, or PostgreSQL databases
- Host email with spam filtering and webmail
- Serve DNS zones
- Back up everything automatically

**Who it's for:**

Anyone running their own servers. Freelancers, agencies, businesses that want control over their hosting instead of renting it.
