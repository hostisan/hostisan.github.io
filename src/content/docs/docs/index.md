Hostisan is a server control panel. It handles websites, databases, email and DNS from one interface. You install it on a fresh Ubuntu server, and it sets everything up.

## Where to start

**New to Hostisan?** Begin with [Your first website](/docs/tutorials/first-website). You'll have a site live in about 15 minutes.

**Ready to install?** Jump to [How to install Hostisan](/docs/how-to/install).

**Looking something up?** The [CLI reference](/docs/reference/cli) covers every command.
